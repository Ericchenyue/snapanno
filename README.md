# SnapAnno — 桌面截图与图片标注工具

Windows 优先的本地桌面截图 + 图片标注软件，基于 Python 3.10+ / PySide6（Qt 6）。
纯本地运行，不联网、无账号、无上传。

核心流程：**打开软件 → 截图 / 编辑 → 拉框截图并确认 → 进入编辑工作台 → 添加标注 → 保存为 JPG 或 .snproj 可编辑图层文件。**

## 二、安装与运行

### 环境要求
- Windows 10 / 11（推荐），Python 3.10 及以上
- 正常登录的**交互式桌面会话**（见「已知限制」）

### 安装依赖

```bat
cd /d D:\AI\SnapAnno
python -m pip install -r requirements.txt
```

`requirements.txt` 内容：

```
PySide6>=6.6,<7
pyinstaller>=6.11     # 仅打包 exe 时需要
```

国内网络如安装慢，可指定镜像：

```bat
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 运行

```bat
python main.py
```

或（Windows 上无控制台窗口）：

```bat
pythonw main.py
```

## 三、使用说明

### 主界面
两个按钮：

| 按钮 | 行为 |
| --- | --- |
| **截图** | 隐藏主窗口 → 桌面出现暗化覆盖层 → 按住左键拉框（实时显示边框与尺寸）→ 松手弹出「确认 / 重新截图」→ 确认后以该截图为底图直接进入编辑页 |
| **编辑** | 进入工作台，先显示选择状态：打开图片 / 打开可编辑图层文件、新建空白画布、返回主界面 |

**截图时 ESC**：取消整个截图流程并恢复主界面。选区过小（< 8 像素）自动忽略、重新等待框选。

### 编辑工作台
- **顶部栏**：保存为图片、保存为可编辑图层文件、打开、**复制**、新建空白画布、**扩大画布**（预览时切换为「应用扩展 / 取消」）、撤销、重做。
- **左侧工具栏**（14 项，V1.2 起每项带简单图标）：选择箭头（置顶）、矩形框、圆形框、椭圆框、矩形填充/蒙版、圆形填充/蒙版、椭圆填充/蒙版、箭头、文字标注、自由画笔、马赛克、模糊、图层上移、图层下移。选中的工具按钮文字显示为**红色**。
- **右侧属性区**：随「当前工具」或「选中图层」自动切换。无选中时编辑工具默认样式；选中图层时直接改该图层。左侧分隔条可拖动改变宽度，切到文字类工具时自动加宽；字体下拉列表独立加宽，不再被挤/覆盖。
- **画布缩放**：状态栏「拖动条 / － / ＋ / 适应窗口 / 100%」。拖动条在「－」「＋」左边，居中为 **100%**，范围 **25%~400%**（对数映射，两端对称）；拖动滑块或点「－」「＋」都会同步右下角百分比并退出自动适应；调整窗口大小不会重置手动比例。普通滚轮仍用于滚动画面。

### 常用操作

| 需求 | 操作 |
| --- | --- |
| 画形状 / 箭头 / 画笔 / 马赛克 / 模糊 | 选对应工具，在画布上按住左键拖动 |
| 添加文字 | 选「文字标注」，在画布上点击，输入文字后确定 |
| 选中图层 | 选「选择箭头」，点击画布上的标注（出现蓝色虚线框与 8 个控制点） |
| 移动 / 缩放 | 选中后拖动图层本体 / 拖动控制点 |
| 删除 | 选中后按 `Delete` / `Backspace`，或属性区「删除标注」 |
| 复制选中标注 | 选中图层后按 `Ctrl+C`，或点属性区「复制标注」：生成一个偏移 18px 的新图层并自动选中（**不写剪贴板、不复制整图**） |
| 复制整图 | 顶部「**复制**」：底图 + 全部标注拼合成图片直接放入剪贴板，可 `Ctrl+V` 粘贴到微信 / Word / 画图等外部程序（不写磁盘、不弹保存框）。成功后按钮短暂显示「已复制 ✓」并弹气泡提示 |
| 缩放画布 | 拖动状态栏滑块（居中 100%，25%~400%），或点「－」「＋」按钮 |
| 扩大画布 | 顶部「扩大画布」→ 图片边缘出现矩形框与 8 个控制点 → 向外拖动 → 属性区「扩展区域颜色」调色（默认白色）→ 点「应用扩展」或「取消」 |
| 绘制完成后 | 自动切回「选择箭头」并选中刚画好的标注，可立即改样式 / 移动 / 再复制 |
| 改图层顺序 | 选中后点左侧「图层上移 / 图层下移」；未选中会提示「请先选择一个标注图层」 |
| 撤销 / 重做 | 顶部按钮，或 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`（上限 60 步） |

### 文件
- **保存为图片 → JPG**：拼合底图 + 全部图层（含填充、文字、马赛克、模糊），默认文件名带时间戳。
- **保存为可编辑图层文件 → .snproj**：ZIP 包，内含 `original.png`（无损底图）、`project.json`（全部图层与样式）、`thumbnail.png`。重新打开可恢复底图与所有图层继续编辑。仅按钮/提示文案改名，文件格式、扩展名、版本号（`PROJECT_VERSION = 1`）均未变，旧文件照常打开。
- **打开**：支持 `.snproj` 以及 JPG / PNG / BMP / GIF / WEBP / TIF 等常见图片；打开图片后可直接标注。
- **新建空白画布**：可选画布颜色与宽高（32~8192 px）。
- **扩大画布**：只向外扩，不允许裁掉原图；应用后扩展颜色**烘焙进底图**（应用前可调、应用后固定），原有全部标注自动平移保持相对位置；此操作是文档级提交，会清空撤销/重做历史，且原工程路径作废、保存时**强制另存为**。

### 快捷键
| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+C` | 复制**当前选中的标注图层**（与属性区「复制标注」相同，不写剪贴板）；仅当输入框里**选中了文字**时才按常规复制文字；无选中时只在状态栏提示 |
| 无滚轮快捷键 | 普通滚轮用于滚动画面；缩放请用状态栏滑块或「－」「＋」 |
| `Delete` / `Backspace` | 删除选中标注 |
| `ESC`（截图流程中） | 取消截图并恢复主界面 |

> 按需求约束，未实现其它工具快捷键体系。

## 四、Windows 打包 exe

### 一键打包（推荐）

```bat
cd /d D:\AI\SnapAnno
python -m pip install -r requirements.txt
python build_exe.py
```

产物：**`dist\SnapAnno v1.2.exe`**（单文件约 44 MB，无需 Python 环境，双击即用）。
exe 名自动取自 `app/config.py` 的 `APP_VERSION`（当前 `1.2`），脚本内部用 Python 字符串传给 PyInstaller，避免命令行编码乱码。
**该 exe 不进 Git 仓库**（`.gitignore` 已忽略 `dist/`）；要分发给他人，可在 GitHub Releases 上传此 exe，或让对方用上面的命令自行打包。
已在本机 PyInstaller 6.22.3 + Python 3.13 下打包并验证：r3 版 exe 启动 5.5 秒出现可见的 `SnapAnno` 主窗口，进程正常无崩溃；归档内 `app.expand_overlay` 等 r3 模块齐全。

`build_exe.py` 会先用 Qt 绘制 256×256 取景框图标 `app_icon.ico`，再调用 PyInstaller：
`--onefile --windowed --clean --icon`，并排除 QtWebEngine / Qt3D / QtQuick / QtMultimedia 等
无关模块以压缩体积。exe 名称使用英文（如 `SnapAnno v1.2`），由脚本内部以 Python 字符串传给 PyInstaller，避免命令行编码乱码。

### 手动等价命令（需要自定义时）

```bat
pyinstaller --name "SnapAnno v1.2" --onefile --windowed --clean ^
  --icon app_icon.ico --exclude-module PySide6.QtWebEngineCore main.py
```

若 cmd 里名字出现编码问题，直接用 `python build_exe.py` 即可。

说明：
- `--windowed` 不弹控制台；若需看报错日志，调试阶段改用 `--console`。
- `--onefile` 首次启动需解压到临时目录（约 3~5 秒），追求启动速度可改 `--onedir`。
- 打包后 `app/` 包会被自动收集，无需手动复制；`selftest.py` 不必打进 exe。
- 中间产物在 `build\pyi\`（可安全删除），重新打包直接再跑一次脚本即可。
- 重打包时脚本会先把同名旧 exe **移动**到 `dist\backup\<名称> (时间戳).exe` 再生成新文件：既保留可恢复版本，也避免 PyInstaller 删除同名文件被环境安全策略拦截。备份确认无用后可自行清理。

### V1.2 修复记录（r2，历史）

> r2 定位的**应用级 `eventFilter` 事件分发机制**和**剪贴板双格式**仍是当前实现基础。
> 但 r3 起：Alt+滚轮只作为底层兜底代码保留，不再宣传、不作为推荐操作；
> `Ctrl+C` 已改为复制选中标注图层，剪贴板整图**仅由顶部「复制」按钮**触发。

用户实测反馈「Alt+滚轮缩放」与「Ctrl+C 复制」不起作用，定位到两处**真实事件路径**问题（逻辑本身没错，但自检原来只直接调函数、用伪造对象，没走事件分发，所以漏检）：

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| Alt+滚轮没反应 | 画布只占滚动区中间一块（例：画布 760×480，viewport 1457×950），鼠标落在图片外的空白/滚动条时，滚轮事件被 `QScrollArea` 吃掉，永远进不了 `Canvas.wheelEvent` | `EditorWindow` 安装应用级 `eventFilter`，统一接管带 Alt 的 Wheel 事件；鼠标在画布外时以画布中心为锚点；Alt 状态用事件修饰键 + 实时按键双保险；状态栏新增「－」「＋」按钮兜底 |
| Ctrl+C 没反应 | ① 焦点在属性面板输入框时，`QAction` 被控件的内置快捷键抢走；② 剪贴板只写 Qt 私有格式，外部程序粘贴兼容性差；③ 复制成功没有任何可见反馈，用户以为没生效 | Ctrl+C 改由同一 `eventFilter` 统一处理（输入框里**有选中文字**才让位给常规复制文字）；剪贴板同时写 `application/x-qt-image` 与标准 `image/png`（实测 .NET 可读到 `DeviceIndependentBitmap` + 760×480 图片）；按钮显示「已复制 ✓」1.5 秒 + 气泡 + 状态栏三重反馈 |

真实平台复核：Alt+滚轮在 viewport 空白区 1.0→1.15 并同步状态栏「115%」；普通滚轮不缩放；
Ctrl+C 在主窗口/画布/工具栏按钮/文字输入框（无选中文字）四种焦点下均复制成功；.NET 外部程序读到图片。

```powershell
$env:QT_QPA_PLATFORM="offscreen"; python selftest.py
```

## 六、实现要点

- **多显示器 / 高 DPI**：遍历所有 `QScreen`，用 `grabWindow(0)` 抓取各屏设备像素图，按
  `screen.geometry()`（逻辑坐标）拼合成「虚拟桌面尺寸 × 主屏 devicePixelRatio」的一张合成图；
  覆盖层铺满整个虚拟桌面，选区（逻辑坐标）乘同一 dpr 即为合成图设备像素坐标，因此不会随缩放错位。
- **图层模型**：每个标注是独立的可 JSON 序列化 dict，渲染 / 命中 / 样式 / 撤销 / 存盘共用同一份数据，避免状态不一致。
- **渲染性能**：已提交图层拼合结果缓存为 `QImage`，仅数据变化时重算；拖拽中的草稿层直接叠加绘制，不重算整图。
- **马赛克 / 模糊**：涂抹式遮挡，每个笔刷采样点从**原始底图**取块后做降采样/平滑处理再贴回，作为独立图层，可移动、缩放、复制、调顺序、撤销重做。强度固定为默认值，不提供强度调节、不提供轮廓。
- **撤销 / 重做**：图层状态快照栈（上限 60 步），因此所有标注操作自动纳入；执行新操作自动清空重做栈；底图独立保存，撤销不影响底图。
- **健壮性**：工程文件加载先校验 ZIP 结构 → 版本 → 图层数据清洗 → 底图，任何异常都转成中文提示而不崩溃；单个图层渲染异常被隔离。

## 七、已知限制

1. **黑屏截图**：Windows 服务、计划任务后台会话、部分远程桌面 / 未登录桌面会话下，
   系统抓屏 API 可能返回纯黑画面。此时程序会弹出中文提示说明原因。
   请在**正常登录的本地交互式桌面会话**中运行。若目标窗口启用了硬件加速保护（部分视频/游戏窗口），也可能抓不到内容。
2. **混合 DPI 多显示器**：不同显示器设置不同缩放比例时，合成图以主屏 dpr 为统一基准，
   非主屏画面可能有轻微缩放重采样，但**不会产生明显坐标错位**。统一缩放比例的多屏环境为 1:1 精确。
3. **外轮廓实现**：描边型图层的「外轮廓」通过先画一圈更粗的底色再画主体实现，
   属于视觉描边，不是矢量 offset 轮廓。
4. 圆形框/圆形填充按拖拽矩形的**内切正方形**绘制，保证是正圆；缩放控制点会保持正方形。
5. 马赛克/模糊采样源固定为原始底图：位于其下方的其它标注在遮挡区域内会被覆盖，
   这符合「对截图内容打码」的直觉，但与「效果叠加在合成结果之上」的图层语义略有差异。
6. 按需求约束，**未实现**：高亮/荧光笔、步骤序号、聚光灯、放大镜、直线/折线（箭头除外）、
   对话气泡、吸色器、工具快捷键体系、云端上传、账号、录屏、OCR、长截图/滚动截图、
   复杂图片美化、水印系统、历史记录管理。
7. **滚轮不用于缩放**：用户实测 Alt+滚轮在不同焦点下仍不稳定，r3 起放弃滚轮缩放，
   统一改用状态栏拖动条 / 「－」「＋」；底层 `wheelEvent` 与 Alt 过滤器代码保留但不作为操作说明。
8. **扩大画布只支持外扩**：控制点向内拖会被钳制，不会裁掉原图；扩展颜色应用后烘焙进底图，
   不能再单独改色（如需换色，撤销不可用，需重新打开扩展前的文件或重做扩展）。
